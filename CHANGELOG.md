# Changelog

## 4.0

- The mod's on-screen messages ("Auto headlights paused" and so on) can now be translated. They go through Codeware's localization system, with English as the fallback for any language that has no translation yet.

Nothing changes in English, and no settings or saves are affected. The Mod Settings page stays in English. See "Translations" in the README if you would like to add a language.
