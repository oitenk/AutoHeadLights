# Changelog

## 4.4.0

NEW! Traffic headlights. NPC vehicles can switch their headlights for night, bad weather and tunnels, using the same settings as yours. Off by default: turn it on under Settings → Mods → Auto Headlights → Traffic.

NEW! Traffic tunnel range setting. Tunnels are checked for traffic this close to you; night and weather apply to all traffic.

NEW! Debug settings: optional logging, and a test switch that makes nearby traffic act as if every road were a tunnel.

Nothing changes for your own vehicle, and no settings or saves are affected.

Beta: traffic headlights have been tested in daytime and with the tunnel test switch. Night, bad weather and switching the option off during play haven't been fully tested yet. Your own vehicle's headlights work exactly as before. Feedback is welcome.

## 4.3.1

Headlights now come on in Nova City 2's darker weather: Gloomy, Meme Clouds, Blackout, Drizzle, Heavy Drizzle, Downpour, Mist and Rain Storm.

Headlights stay off in Nova City 2's brighter weather that only sounds gloomy: Distant Rain, Haze Pollution and Light Drizzle.

Nothing changes with the game's own weather, and no settings or saves are affected.

## 4.3

- Mod Settings is now optional. Without it, Auto Headlights loads with its default settings; with it, everything can be changed in game as before.
- Checked against the latest game patch and Codeware.

Nothing changes if you already use Mod Settings, and no settings or saves are affected.

## 4.2

- Now works alongside Enhanced Vehicle System. When EVS is installed, Auto Headlights keeps EVS's own headlight state in step with its decisions, so the two no longer disagree about whether the lights should be on.
- Flashing the headlights with EVS no longer pauses auto mode.

If you use EVS, turn off its headlights time sync so only one mod decides when the lights come on. Nothing changes if you don't use EVS, and no settings or saves are affected.

## 4.1

- Fixed sprint not working on foot after summoning a vehicle, which could happen on some setups. The mod now only listens for the headlight key while you are driving. Thanks to kasperfinn for the report and the fix.

Nothing changes while driving, and no settings or saves are affected.

## 4.0

- The mod's on-screen messages ("Auto headlights paused" and so on) can now be translated. They go through Codeware's localization system, with English as the fallback for any language that has no translation yet.

Nothing changes in English, and no settings or saves are affected. The Mod Settings page stays in English. See "Translations" in the README if you would like to add a language.
